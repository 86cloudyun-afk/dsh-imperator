迁移是事务中补列/建表：task 增加 owner_session、evidence_policy、verification_files/command/cwd、evidence_generation；fact 增加 actor_session；增加 execution_receipt/waiver。governor 显式初始化增加 run/reservation/retry_charge/hold/audit 表及索引。旧行不猜填身份/回执，未绑定兼容路径有警告；旧 trim 身份无法还原。保守 governor 历史 retry 迁移可能多计，旧未证明 reservation bind 被拒，须可信主控审计恢复。

严格验收为 opt-in execution，默认 legacy；人工 waiver 为非验证通过。分页 tasks/summary 工具 JSON 上限65536 UTF-8 bytes，默认25/最大100，详情/显式原文历史页只限条数。增量 reducer 仍有 O(n) 前缀扫描/复制和冷认证；可变恢复历史全重放，不推导整步 O(1) 或模型延迟改善。

durable governor 是单独可信宿主 core。原生 adapter 无条件阻断 H01–H06（session 身份、完整准入、durable flush/lookup、子树与进程静默、排他 owner/recovery、可信 workspace）；prompt 预算仍软约束。STALL observe / stepDownRequests: 0、宿主 approval/sandbox/guards 保留。接口 run 隔离不能替代文件系统隔离，同 UID 的 unrestricted shell 可物理改库与日志。

最终记录将区分执行付费模型的候选 archive 与文档补齐后的最终 archive，列各自 SHA256 与相同产品源码 fingerprint；不声称模型跑过不同 SHA 的最终包，也不在归档中自引用尚未存在的本提交/SHA。金额 fixture 只支持自包含同步 ESM sumMoney 与标准 ECMAScript 内建，禁止 money.mjs imports/Node globals/异步返回；固定 grader 子进程 vm realm 不是 OS 沙箱。
