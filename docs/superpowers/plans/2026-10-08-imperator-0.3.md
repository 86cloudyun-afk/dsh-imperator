# Imperator 0.3.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将实测发现转化为可信身份、严格执行验收、有界与增量读取、持久准入基础及可重复模型回归，并经过独立审核合并。

**Architecture:** 保留已有 TaskforceStore 与原生 preset，新增 focused helper 模块。工具层提供可信身份和宿主执行接线，数据层负责事务与持久判据。governor 是单独可信宿主 API，未验证的 native managed 接入明确阻断。

**Tech Stack:** Node built-ins、node:sqlite、DSH 0.2.0-rc.2、node:test；无外部运行依赖。

**Spec:** `docs/superpowers/specs/2026-10-08-imperator-0.3-design.md`

## Global Constraints

- 包名 `@local/dsh-taskforce`、preset `taskforce`、显示名 `任务部队`、数据库 `$DSH_HOME/taskforce/taskforce.db` 不变。
- Node `^22.23.2 || ^24.19.0`；宿主验收 `@deepseek-ai/dsh@0.2.0-rc.2`；目标包版本 `0.3.0`。
- 零外部运行依赖；主会话只读调查与验收，子会话执行；保留宿主 approval/sandbox/guards。
- STALL 仅观察，`stepDownRequests: 0`；跨 run、终态、late blocker、PTC/native identity 不退化。
- 新测试登记 runner TESTS 与 verify-runner 镜像；pack 中缺仓库专有文件可说明 SKIP，源码树缺文件必须失败。
- 每任务先测试并看到正确失败，再实现、定向验证、npm test、提交；reviewer 不能修改产品。
- 不修改 `.github/workflows`；沿用已有双 Node packed-native CI。PR 和 merge 已授权。

## Review Focus

- 昵称相同但真实 session 不同：后者不能抢绑定、提交或取消；对应 Task 1。
- 代码/日志/代数/owner 在运行后变化：旧成功不再可验收；对应 Task 2。
- 大标题、多晚到 blocker 与并发新增：默认输出有界且游标可以取回全部；对应 Task 3。
- 冻结历史中段 replacement 与未冻结对象就地修改：增量结果等于全量重放；对应 Task 4。
- 多连接竞争、unknown 重启及重复 operation key：不得超额或提前释放；对应 Task 5。

### Task 5: 持久 governor 核心与能力阻断

**Files:** Create `lib/governor/index.js`, `lib/governor/native.js`, `tools/tests/governor.test.mjs`, `docs/GOVERNOR.md`; Modify package exports、runner+mirror。

**Interfaces:** Produces `new TaskforceGovernor(store)`，方法 `reserve(input,runId,authority)`、`bind(input,runId,authority)`、`markUnknown(input,runId,authority)`、`settle(input,runId,authority)`、`snapshot(runId)`、`extendBudget(input,runId,authority)`。authority 为模型工具不可触达的可信宿主 `{role:'lead'|'worker',sessionId}`；operation_key/task_id/mode(read|write)/kind(new|reuse|retry)/resources 是 reserve 输入，返回 durable reservation_id/generation/state。后续 input 必须带 reservation_id/generation。native `createNativeGovernorAdapter()` 无论配置均抛 `E_SCHEDULER_CAPABILITY` 并列未解除的 H01–H06，不能开启虚假保证。

- [ ] 失败测试：全 run active_total 6/writers2、新建3/retry每task2；reuse/嵌套同 run；不同run同resource writer互斥、reader共享；operation key payload不同拒绝；过期generation拒绝；多 SQLite connections争抢最后slot；cancel/idle不释放；unknown 重启仍占用；only never_started 或 terminal+trusted quiescence settle才释放；lead 扩额需要reason和audit。
- [ ] Run `node --test tools/tests/governor.test.mjs`，确认 missing governor/admission失败。

- [ ] settle 只接受可信端口已证明的 never_started 或 terminal+quiescence；文档明确该端口不制造 OS 证明，无 native production adapter/queue/autodelivery。scope 与 task ownership校验、SQL fault rollback、closed store行为必须验证。导出 `./governor`。
